# 🚔 GATE - Portal Operacional

Portal completo para gestão operacional de polícia virtual em GTA RP. Sistema de relatórios, ranking, aprovações e administrativo.

## ✨ Funcionalidades

- 🔐 **Autenticação:** Login seguro com usuário e senha
- 📋 **Relatórios:** Agentes podem criar relatórios de patrulhamento
- ✅ **Aprovação:** Admin aprova ou rejeita relatórios
- 📈 **Ranking:** Sistema de ranking com estatísticas de agentes
- 👮 **Gestão:** Visualizar agentes, regras, viaturas e fardamentos
- 📊 **Dashboard:** Painel com estatísticas em tempo real

## 🛠️ Tecnologia

- **Backend:** Node.js + Express
- **Frontend:** HTML + CSS + JavaScript puro
- **Banco de Dados:** SQLite
- **Autenticação:** bcryptjs + express-session

## 📋 Pré-requisitos

- Node.js v14+ instalado
- npm (vem com Node.js)

## 🚀 Instalação e Teste Rápido

### 1️⃣ Clonar o repositório
```bash
git clone https://github.com/Gremiista/gate-portal.git
cd gate-portal
```

### 2️⃣ Instalar dependências
```bash
npm install
```

### 3️⃣ Iniciar o servidor
```bash
npm start
```

### 4️⃣ Abrir no navegador
Acesse: **http://localhost:3000**
